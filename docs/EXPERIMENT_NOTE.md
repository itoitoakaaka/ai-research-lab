# Lab A 実験ノート（2026-11-21）

## 目的
小規模な多層パーセプトロンによる非線形回帰を使い，訓練データ数，ノイズ，ネットワークの深さ・幅，学習率が学習および汎化に与える影響を確認する．これは合成データの教育用実験であり，査読付き研究成果ではない．

## 課題
真の関数：`y = sin(3x) + 0.3x`．観測値にはガウス雑音を加える．損失はMSE．最適化はAdam．

## 設計
基本条件は訓練60点，ノイズ標準偏差0.2，隠れ層2層（幅32），学習率0.01，200 epoch．8条件，各5 seed．

## 主要な観察
- 20点では訓練MSEが低い一方，検証MSEが高くなった．
- 300点では検証MSEが改善した．
- 学習率0.0001では200 epochでは収束不足の可能性がある．
- 深さ・幅を増やしても必ずしも改善しない．

## 限界
5 seedの記述統計にすぎず，統計的な優越性の確証ではない．検証データも乱数によって変わる．公開用の再現スクリプトは整理版であり，前回生成済みのCSVとの厳密一致は未検証．再実行した場合はバージョンや結果を記録して比較すること．
